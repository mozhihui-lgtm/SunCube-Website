# SunCube Website

Static website for SunCube's agrivoltaic systems.

## Local preview

Run a local web server from the project folder:

```bash
python3 -m http.server 4173
```

Then open `http://127.0.0.1:4173/`.

## Main files

- `index.html` — page structure and content
- `styles.css` — layout and visual styles
- `script.js` — navigation and page interactions
- `assets/images/` — website images
- `Logo/` — SunCube logo assets

## Large source files

The pitch deck and other large source documents are intentionally excluded from Git. Store them in the team's shared cloud drive and link them separately when handing the website to a collaborator.
